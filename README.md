# 环盖驯马

[在线游玩](https://bingqilin456.github.io/huangai-horse-taming/)

青铜器主题互动游戏，支持七马通关与无尽挑战、键盘、标准手柄和触摸操作。

无尽每轮七马后挑战高难度双虎，三格勇气，海贝道具跨轮保留，历史纪录按难度独立保存。

GitHub Pages 从 main 分支根目录发布。网页文件须一起保留；首次加载约80 MB素材。

177项自动化测试通过，已验收两轮无尽、守关重试、纪录读档和普通模式切回。

音乐、图片、馆长配音与文物解读的来源及创作说明保留在游戏内，三维渲染库许可证保留在对应脚本中。游戏演绎不作为文物史实。
